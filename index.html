refactor.log

Engineering the vibe code

Vibe coding accepts the first output. Vibe engineering reviews it. Three edits I made to the AI's drafts while building this site:

🔧index.html › hero photo A missing file should never render a broken image.
<figure class="specimen"> <img src="assets/img/cynthia.jpg" alt="Cynthia"> <span class="photo__mono">CA</span> <!-- default --> <img class="photo__img" alt="Portrait of Cynthia Ojoma Abah" src="assets/img/cynthia.jpg" onload="this.closest('.specimen').classList.add('has-photo')"> </figure>
Why: the vibe draft assumed the photo exists. I engineered a styled monogram fallback and an onload hook, so the page is presentable before the real image is added and upgrades itself the moment it is.
🔧app.js › nav + smooth scroll Keyboard and screen-reader users are first-class, not an afterthought.
<div class="nav-item" onclick="scrollTo('projects')">Projects</div> <a href="#projects">Projects</a> <!-- real anchor: focusable, --> <!-- works without JS, right-click/open-in-new-tab, announced by AT --> section{ scroll-margin-top: calc(var(--head-h) + 14px); }
Why: a div onclick isn't reachable by keyboard and says nothing to a screen reader. Semantic <a> anchors give focus, native behaviour and correct scroll offset under the sticky header — for free.
🔧CV › Moniepoint bullet Never ship a number you can't stand behind.
…cutting average issue-lookup time by ~25% [verify] …streamlining case handling and reducing average issue-lookup time
Why: the source draft carried a self-flagged [verify] figure. Rather than assert an unverified metric on an ATS CV, I kept the real achievement and dropped the number — reinstate it only if it can be confirmed.

Single offline HTML file — no framework, no CDN."
